# Python from scratch

Projects built from an empty file in Python, one folder per [itsPyguru](https://github.com/itspyguru) video.

| Folder | What it builds |
|---|---|
| [redis-style-cache](redis-style-cache) | In-memory cache: TTLs, a cleaner thread, a stampede fix, LRU eviction |
| [load-balancer](load-balancer) | Round robin across 3 FastAPI backends, health checks, a kill-a-server test |
| [pdf-chat](pdf-chat) | AI PDF chat app: LangChain RAG over FAISS, Gemini via OpenRouter, Streamlit chat with page sources |
| [telegram-ai-bot](telegram-ai-bot) | Telegram AI assistant: python-telegram-bot + Gemini via OpenRouter, per-chat memory, photo questions, private to you |

These are teaching builds, not production replacements.
